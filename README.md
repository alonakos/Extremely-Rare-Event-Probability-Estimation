# Quantum Sampler for Extremely Rare-Event Probability 


Exploratory work on quantum circuit representations for rare-event probability estimation.

## Overview

Rare-event estimation asks how likely a system is to reach an unusual outcome, such as a particular combination of equipment failures or a critical threshold being crossed. Direct sampling becomes expensive when the event is unlikely enough that most trials never observe it. This project explores how (and if) these problems can be encoded in quantum circuits. The focus is on representing paths, marking target events, and understanding the gate and qubit requirements of different designs.
